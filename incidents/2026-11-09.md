# Incident 2026-11-09: health check blind after runner image change

|          |                                                                                                                                                  |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| Detected | 2026-11-24 by a maintainer reading [health-check run 45349183985](https://github.com/wulfland/Repstack/actions/runs/45349183985); no alert fired |
| Started  | 2026-11-09 07:35 UTC, [health-check run 42580278988](https://github.com/wulfland/Repstack/actions/runs/42580278988)                              |
| Resolved | Pending: first green health check after this PR is merged                                                                                        |
| Duration | 15 days without a working production probe; production itself stayed up                                                                          |
| Issue    | None: the pipeline did not open one (see root cause)                                                                                             |
| Fix PR   | This PR                                                                                                                                          |

## Timeline (UTC)

- 2026-10-20 09:09 last deploy of `main` (`b94fac0`), [deploy run 39398647956](https://github.com/wulfland/Repstack/actions/runs/39398647956), green. No deploy since.
- 2026-11-06 07:35 last green [health-check run 42181890177](https://github.com/wulfland/Repstack/actions/runs/42181890177), on runner image `ubuntu-24.04`.
- 2026-11-09 07:35 [health-check run 42580278988](https://github.com/wulfland/Repstack/actions/runs/42580278988) gets `ubuntu-26.04` for `ubuntu-latest`. `npx playwright install chromium --with-deps` fails with "Playwright does not support chromium on ubuntu26.04-x64". The production probe step is skipped; no incident issue is opened.
- 2026-11-09 to 2026-11-24 every scheduled run (12 in total) fails the same way.
- 2026-11-24 diagnosis: the probe never ran. `curl` against production returns 200; production was not affected.

## Root cause

GitHub moved the `ubuntu-latest` label from Ubuntu 24.04 to 26.04. Playwright
1.58.0, pinned in `package-lock.json`, has no Chromium build or dependency list
for Ubuntu 26.04, so the "Install Playwright browsers" step fails before the
probe runs. No commit in this repository caused it; the deploy run linked
above is the one serving production throughout, not a cause.

The pipeline stayed silent because the `alert` job only runs when
`needs.probe.outputs.production_check == 'failure'`. That output comes from
the probe step, which was skipped, so a broken probe job looks like "no
failure" and neither the issue nor the rollback fires. The only signal was a
red run in the Actions tab.

## Blast radius

No user impact. Production stayed up on the 2026-10-20 deploy. For 15 days
nothing would have detected a broken production deploy, and the next deploy's
E2E stage (`deploy.yml`, also `ubuntu-latest`) would have failed the same way.

## Remediation

None needed for production. No rollback or workflow dispatch was performed.

## Permanent fix

This PR pins the two jobs that install Playwright browsers (`probe` in
`health-check.yml`, `e2e-test` in `deploy.yml`) to `ubuntu-24.04` instead of
`ubuntu-latest`. Runner image moves then become a deliberate change made
together with a Playwright upgrade, not a surprise.

## Follow-ups

- [ ] Open an issue (without rollback) when the probe job fails before the
      production check runs, so a broken monitor is not silent.
- [ ] Upgrade `@playwright/test` to a release that supports Ubuntu 26.04, then
      move the pinned jobs forward.
- [ ] Confirm a green health check after merge (`gh workflow run health-check.yml`).
